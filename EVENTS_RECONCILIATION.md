# Events Reconciliation (EP-1.5)

This document maps every event type defined in the two agent repos onto the
single canonical vocabulary in
`src/iab_agentic_primitives/events/models.py` (`EventType`) of this shared
contract library for IAB (Interactive Advertising Bureau) agentic advertising.

Sources reconciled:

- **Buyer**: `buyer-agent/src/ad_buyer/events/models.py` — 38 event types
- **Seller**: `seller-agent/src/ad_seller/events/models.py` — 22 event types

Result: **52 canonical event types**. Of the 60 source values, 8 seller values
were dropped as duplicates of a buyer value with the same meaning (7 had
identical strings; 1 — `approval.denied` — had a different string). 3 source
values were renamed (see notes in the tables). Machine-readable renames live
in `LEGACY_ALIASES` in the models module.

Emitter conventions: `quote.*`, `campaign.*`, `budget.*`, `order.*`,
`inventory.*`, `pacing.*`, `creative.*`, `portfolio.*` are buyer-emitted;
`proposal.*`, `package.*`, `execution.*` are seller-emitted; `deal.*`,
`negotiation.*`, `approval.*`, `session.*` may be emitted by either agent,
disambiguated by `source_agent`.

## Naming decisions

1. **`approval.rejected` over `approval.denied`** — one word for the negative
   approval outcome; "rejected" matches the buyer repo and the seller's own
   `ApprovalStatus.REJECTED` / `proposal.rejected` usage.
2. **`campaign.cancelled` (double "l")** — the buyer repo mixed spellings
   (`deal.cancelled` vs `campaign.canceled`); the canonical vocabulary uses
   "cancelled" consistently.
3. **`order.submitted` replaces `booking.submitted`** — the single "booking"
   event moves into the `order.*` domain; "booking" survives only inside the
   campaign lifecycle phases (`campaign.booking_started` / `_completed`).
4. **`quote.*` and `proposal.*` both kept** — they are the buyer- and
   seller-side views of the same request-for-quote exchange, but they mark
   different local moments (buyer asked / buyer got an answer vs seller
   received / evaluated / decided), so merging them would lose information.
5. **`timestamp` renamed to `occurred_at`** — and made strictly
   timezone-aware UTC (Coordinated Universal Time), fixing the seller's naive
   `datetime.utcnow` default.
